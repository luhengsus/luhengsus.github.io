1️⃣ 建立骨盆和下肢 Model 基础

视频：【学完怕忘】Visual 3D（一）建立骨盆和下肢Model

🔑 关键步骤

  • 1. 导入 C3D 文件 → File → Open → 选择静态标定文件
  • 2. 创建 Pelvis Segment → 使用 RASI/LASI/RPSI/LPSI 标记点定义骨盆坐标系
  • 3. 定义骨盆原点 → 以双侧髂前上棘中点作为骨盆中心
  • 4. 创建 Thigh Segment → 使用 LTHI/RTHI + LKNE/RKNE 标记点
  • 5. 创建 Shank Segment → 使用 LTIB/RTIB + LANK/RANK 标记点
  • 6. 定义关节中心 → 髋关节用球心拟合，膝关节用铰链近似

2️⃣ 建立虚拟坐标轴（足）进阶

视频：【学完怕忘】Visual 3D（二）建立虚拟坐标轴（足）

🔑 关键步骤

  • 1. 创建 Foot Segment → 使用 LHEE/RHEE + LTOE/RTOE + LMT5/RMT5
  • 2. 建立虚拟坐标轴 → Build → Virtual Lab → Create Coordinate System
  • 3. 定义足背屈/跖屈轴 → 以踝-第1跖骨连线为 Z 轴
  • 4. 定义内外翻轴 → 以跟骨-第5跖骨连线为 X 轴
  • 5. 验证坐标系方向 → 检查右手定则一致性
📸 关键帧占位
建议截图：虚拟坐标轴建立后的足部分段 3D 视图

3️⃣ 建立胸廓 Model 躯干

视频：【学完怕忘】Visual 3D（四）建立胸廓Model

🔑 关键步骤

  • 1. 创建 Thorax Segment → 使用 C7/T10/STRN/CLAV 标记点
  • 2. 定义胸廓坐标系 → Z 轴：T10→C7；X 轴：垂直于矢状面
  • 3. 与骨盆建立关联 → 确保腰椎关节中心正确连接
  • 4. 验证躯干姿态 → 站立姿态下脊柱应接近竖直
📸 关键帧占位
建议截图：Thorax Segment 与 Pelvis 的连接关系 3D 视图

4️⃣ 建立上肢 Model 上肢

视频：【学完怕忘】Visual 3D（五）建立上肢Model：上

🔑 关键步骤

  • 1. 创建 Upper Arm Segment → 使用 LUPA/RUPA + LELO/RELO
  • 2. 创建 Forearm Segment → 使用 LELO/RELO + LWRA/RWRA + LWRB/RWRB
  • 3. 创建 Hand Segment → 使用 LWRA/RWRA + LFIN/RFIN
  • 4. 定义肩关节中心 → 基于功能方法（Functional Method）拟合球心
  • 5. 定义肘关节轴 → 以肱骨外上髁-内上髁连线为铰链轴
  • 6. 验证上肢姿态 → 自然下垂时肘角约 5-10° 屈曲

5️⃣ 建立 CMO/CMZ（整合多个 C3D 文件）整合

视频：【学完怕忘】Visual 3D（七）建立CMO/CMZ（整合多个C3D文件）

🔑 关键步骤

  • 1. 准备多文件 → 静态标定文件（Calibration）+ 动态 trial 文件
  • 2. 创建 CMO（Calibration Model Object） → Model → Build Model From → Multiple Files
  • 3. 指定标定文件 → 选择包含完整标记点的静态文件
  • 4. 创建 CMZ（Calibration Model Zipped） → 导出压缩模型文件
  • 5. 应用到动态文件 → 用 CMZ 批量处理多个动态 trial
  • 6. 验证标记点覆盖 → 确保每个 trial 的标记点都被模型识别
📸 关键帧占位
建议截图：CMO 创建完成后的多文件模型树结构

6️⃣ 导数据（OpenSim / C3D / MATLAB）导出

视频：【学完怕忘】Visual 3D（八）导数据

🔑 关键步骤

  • 1. 导出 C3D → File → Export → C3D（保留标记点和模型数据）
  • 2. 导出 TRC / MOT → 用于 OpenSim：标记点轨迹 + 关节角
  • 3. 导出 ASCII → 文本格式，便于 MATLAB/Python 读取
  • 4. 导出 OpenSim 配置 → 使用模板生成 .xml 和 .osim 文件
  • 5. 批量导出 → 利用 Pipeline 脚本批量处理多个 trial

📎 附录：Qualisys 标记点命名（全身）前置

视频：【学完怕忘】Qualisys mark点命名（全身）

🔑 标记点命名规范（Plug-in-Gait 全身模型）

  • 骨盆：RASI / LASI / RPSI / LPSI（髂前/后上棘）
  • 大腿：RTHI / LTHI（大腿外侧）；RKNE / LKNE（膝外侧）
  • 小腿：RTIB / LTIB（小腿外侧）；RANK / LANK（踝外侧）
  • 足部：RHEE / LHEE（跟骨）；RTOE / LTOE（第1跖骨）；RMT5 / LMT5（第5跖骨）
  • 躯干：C7 / T10 / STRN / CLAV
  • 上肢：RUPA / LUPA / RELO / LELO / RWRA / LWRA / RWRB / LWRB / RFIN / LFIN
